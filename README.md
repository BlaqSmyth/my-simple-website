
## 🚀 Features

- Responsive basic layout
- Clean and simple design
- HTML for structure, CSS for styling

## 🛠 How to Run Locally

1. Download or clone this repository.
2. Navigate to the project folder.
3. Open the `index.html` file in your browser by double-clicking it or right-click > "Open with browser".

## 🎯 Purpose

This project is intended for educational purposes to help beginners understand:
- Basic HTML structure
- Linking external CSS
- Building and testing a static website locally
